# Changelog

## 14.0.0 - 2026-05-29

### Breaking

- Require TYPO3 14.3 or later and PHP 8.3 to 8.5.
- Drop TYPO3 12 and TYPO3 13 support.
- Move TypoScript and Page TSconfig integration to a TYPO3 site set.

### Changed

- Update development tooling for TYPO3 14, PHPStan max level, PHPUnit 12,
  and TYPO3 testing-framework 9.
- Add DDEV PHP 8.4 configuration and TYPO3 Solr add-on configuration for the
  EXT:solr 14 configset.
